# Generative AI Statement

> Place this section before the References. Both versions below follow the
> official wording required by the respective publishers. The statement is
> deliberately brief: it records the permitted auxiliary use without
> attributing any part of the scientific contribution to a tool.

## Version for Neurocomputing (Elsevier)

**Declaration of generative AI and AI-assisted technologies in the manuscript preparation process**

During the preparation of this work the authors used general-purpose language
assistance tools in order to improve the readability and language of the
manuscript and to assist with routine code formatting. After using these
tools, the authors reviewed and edited the content as needed and take full
responsibility for the content of the publication. The tools were not used
to generate or modify experimental data, figures, or the scientific claims
of this paper, and no AI tool is listed as an author.

## Version for IEEE TMM

**Use of AI-assisted technologies**

The authors used AI-assisted language tools to improve the clarity and
readability of the manuscript and to support routine code formatting. The
authors have reviewed all outputs and take full responsibility for the
content of the paper. No generative AI tool was used to create experimental
results, figures, or the core scientific contributions, and no AI tool is
listed as an author.

---

## Notes on wording

- Both statements name only auxiliary uses (language editing, code formatting),
  which are the uses publishers explicitly permit with a declaration.
- The phrase "reviewed and edited ... take full responsibility" is required
  by Elsevier; keep it verbatim.
- The explicit denial of data/figure generation matters: both Elsevier and
  IEEE state that AI must not generate or alter experimental images or data.
- If the journal's submission system offers a structured AI-declaration form,
  copy the same content into it rather than attaching this file only.
