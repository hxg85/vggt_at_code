## Version for Neurocomputing (Elsevier)

All experiments in this work are conducted on publicly available datasets:

- **SS3DM**: Synthetic street-scene 3D reconstruction dataset, available at
  https://ss3dm.top/. Ground-truth point clouds were generated with the
  `extract_gt_pcd.py` script released in https://github.com/THU-LYJ-Lab/SS3DM-Benchmark.
- **DTU MVS Dataset**: https://roboimagedata.compute.dtu.dk/?page_id=36.
  The standard 15 test scans (24, 37, 40, 55, 63, 65, 69, 83, 97, 105, 106,
  110, 114, 118, 122) and the sparse-view protocol described in Section 3.1
  were used.
- **Tanks and Temples**: https://www.tanksandtemples.org/download/. The
  intermediate set was evaluated through the official online benchmark,
  since ground truth for the test scans is withheld.

The source code implementing the proposed VGGT-AL method is publicly
available at https://github.com/hxg85/vggt_at_code, together with data
preparation scripts, training and evaluation code, and configuration files
that reproduce the reported experimental settings. The scene-level split
used for SS3DM is recorded in the manifest files generated by
`scripts/prepare_ss3dm.py` and is included in the repository.

## Version for IEEE TMM

The data supporting the results of this paper are openly available: SS3DM
(https://ss3dm.top/), the DTU MVS Dataset
(https://roboimagedata.compute.dtu.dk/?page_id=36), and Tanks and Temples
(https://www.tanksandtemples.org/download/). The reference point clouds for
SS3DM were produced with the publicly released extraction script at
https://github.com/THU-LYJ-Lab/SS3DM-Benchmark. For Tanks and Temples, results
were obtained through the official evaluation server, as test-set ground
truth is not distributed. The complete implementation, including data
preparation, training and evaluation scripts and the experimental
configurations, is released at https://github.com/hxg85/vggt_at_code.
